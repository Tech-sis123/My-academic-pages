Served as a **Software Engineering Tutor** at the Engineering Career Expo (ECX) from September 2025 to February 2026, teaching backend engineering to **60+ developers** across the programme cohort.

Topics covered included:

- **Backend fundamentals** — RESTful API design, authentication and authorisation patterns, database modelling
- **Python for backend development** — FastAPI, Django REST Framework, ORM usage, environment management
- **API security and best practices** — input validation, rate limiting, JWT, HTTPS
- **Project-based learning** — participants built and deployed small backend projects by end of the programme

ECX is a career development initiative aimed at bridging the skills gap between Nigerian engineering graduates and industry-ready software engineering roles.
