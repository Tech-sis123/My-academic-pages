**Microsoft AI Skills Hackathon 2026 — 1st Place**

VoiceIQ is a real-time conversation intelligence layer for Nigerian telecom call centres, built to handle English/Pidgin code-switching that existing NLP tools misclassify as noise.

**Components:**
- Utterance-level language identification for Nigerian English, Pidgin, and mixed-code speech
- Sentiment analysis applied per-language segment
- XGBoost churn prediction model with SHAP explanations surfaced to agents in real time
- Agent Action Cards: mid-call prompts for retention offers, escalation triggers, and next-best-action

I led the product idea and pitch. Team: Akeem Odebiyi, Yusuf Abdulwahab.
